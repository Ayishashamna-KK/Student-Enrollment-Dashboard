#Student Enrollment & Course Analysis Dashboard
 Project Overview

The Student Enrollment & Course Analysis Dashboard is a data analytics project designed to analyze student enrollment patterns, course performance, branch-wise distribution, payment status, and revenue generation.

This project contains two interactive dashboards that provide insights into student enrollment, course popularity, payment collection, and course completion rates.

The main objective is to help educational institutions monitor student performance, understand enrollment trends, evaluate course revenue, and make data-driven business decisions.

🎯 Project Objectives

Analyze total student enrollment and course completion.

Identify monthly student enrollment trends.

Understand popular courses and course categories.

Compare student enrollment across different branches.

Analyze online, offline, and hybrid learning modes.

Monitor payment collection and outstanding payments.

Evaluate course-wise revenue generation.

Analyze course fees and course duration.

Identify completion rates across different courses.

Key Insights

The dashboard represents approximately 2,000 students.

993 students have completed their courses.

1,007 students are currently ongoing.

The overall completion rate is 49.65%.

Data Analytics has the highest enrollment, with 159 students.

Abu Dhabi has the highest branch enrollment, with 363 students.

Online learning has the highest student count, with 685 students.

📝 Conclusion

The Student Enrollment & Course Analysis Dashboard transforms raw enrollment and payment data into meaningful business insights.

The project provides a comprehensive overview of student enrollment, course popularity, branch performance, learning modes, payment collection, revenue generation, and course completion.

By analyzing these factors, educational institutions can identify enrollment patterns, improve course completion rates, strengthen payment collection strategies, and make informed decisions to improve overall institutional performance.
